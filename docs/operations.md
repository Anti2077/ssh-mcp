# 日常维护

## 查看和停止服务

```bash
./bin/ssh-mcp status
```

状态命令会显示 daemon 是否运行、凭据库是否锁定以及活动 bridge 数量。

```bash
./bin/ssh-mcp stop
```

普通停止只在没有活动 MCP bridge 会话时执行。需要中断活动客户端会话时，必须在交互终端执行：

```bash
./bin/ssh-mcp stop --force
```

程序会连续两次要求输入精确的 `yes`。强制停止可能使正在进行的远程操作返回 `outcome_unknown`，停止后应人工核验远端状态。

## TUI 键盘操作

- 主页：`↑↓` / `Tab` 选择菜单，`Enter` 打开。
- 目标列表：`Tab` 在目标列表与纵向操作菜单之间切换焦点，`↑↓` 在当前组选择目标或操作，`Enter` 执行，`Esc` 返回目标列表。
- 表单：`Tab` / `Shift+Tab` 选择字段和保存/取消按钮，`Enter` 确认；`Ctrl+S` 也可提交。
- 确认页：`←→` 切换按钮，`Enter` 确认；默认“返回”。
- `Esc` 返回，`Ctrl+C` 退出。主页还提供语言、备份、主密码和数据密钥维护菜单。

私钥认证与口令处理见[私钥登录](private-key-auth.md)。

### 在输入框中粘贴

TUI 只接受**终端自己的粘贴**：`Shift+Ins`、`Cmd+V`，或终端右键菜单的粘贴。粘贴内容由终端以一次事件送入，TUI 不会读取操作系统剪贴板，因此在 SSH 会话和无图形界面的环境中同样可用。

`Ctrl+V` 不执行粘贴，会提示改用终端粘贴。

粘贴内容在写入输入框前会被清洗，不符合要求的粘贴会被忽略，输入框保持原样：

| 情况 | 结果 |
| --- | --- |
| 首尾空白（含换行、制表符、不间断空格、全角空格） | 自动去除后再写入。 |
| 去除首尾空白后仍含空白字符 | 忽略，提示“粘贴内容包含空白字符”。 |
| 超过长度上限（密码字段 256 字符，其他字段 1024 字符） | 忽略，提示“粘贴内容超过长度上限”，不截断、不回显实际长度。 |
| 内容为空 | 提示“粘贴内容为空”。 |

私钥口令页保留空格，私钥路径允许空格；两者拒绝控制字符。

密码字段粘贴成功后只提示“已粘贴”，不显示字符数；其他字段会显示粘贴的字符数。

## 备份和恢复

### 创建备份

1. 在主页选择“创建加密备份”，按 `Enter`。
2. 输入备份文件路径和当前主密码。
3. 将生成的加密备份放在受信任位置，并限制其操作系统权限。

备份包含本地状态快照和加密凭据，不包含运行时 socket、PID 或私钥文件。

### 恢复备份

1. 先结束使用该实例的 MCP 客户端会话。
2. 在 TUI 选择“从备份恢复”，输入备份源路径、恢复目标路径和主密码。
3. 恢复前会校验备份格式和内容，并使用临时文件替换目标。
4. 重启 daemon 后检查 `status` 和目标列表。

建议先恢复到独立文件，再按计划替换正在使用的 `state.db`；不要在 daemon 正在读写时直接覆盖活动数据库。恢复不会自动复制 `.ssh-mcp-runtime/`。

## 密钥维护

- **轮换数据密钥**：主页选择“轮换数据密钥”，输入 `ROTATE` 和当前主密码。完成后当前远程连接和 SSH 工作会话会被清理，后续请求会重新建立连接。
- **修改主密码**：主页选择“更改主密码”，输入当前主密码和新主密码。修改后用新密码解锁。
- **锁定**：主页选择“锁定凭据库”，或关闭 daemon。锁定后必须重新解锁才能进行远程操作。

## 审计日志

`audit.log` 位于程序同目录。它是 JSONL 文本，记录操作时间、目标、操作类别、策略结果和有限的结果元数据；不会保存完整远端输出、文件内容或部署内容。

日志默认达到 20 MiB 时轮换，保留 10 个归档。审计用于本地追溯，不是防篡改证据。审计写入失败时，先查看工具返回的 `execution_outcome`，不要把审计状态当作远端执行状态。

## 更新和迁移

1. 退出所有使用该实例的 MCP 客户端会话。
2. 执行 `./bin/ssh-mcp stop`。
3. 优先在 TUI 创建加密备份。若必须手工复制，确认 daemon 已停止，并同时处理 `state.db`、`state.db-wal`、`state.db-shm`（如存在）以及全部 `audit.log` 轮转归档。
4. 替换程序后，从新路径重新注册 `ssh-mcp` MCP server。
5. 运行 `./bin/ssh-mcp manage` 检查目标和解锁状态。

`.ssh-mcp-runtime/` 中的本地 socket、PID 等文件可以删除并自动重建；不要把它当作持久数据备份。使用加密备份迁移时不需要复制这些运行时文件。
macOS 安装路径过长时，这些文件会放在 `/private/tmp/ssh-mcp-<用户ID>-<安装目录哈希>/`。只在 daemon 停止后清理对应运行目录；数据库和审计日志仍在程序目录。

## 故障排查

| 问题 | 建议 |
| --- | --- |
| `daemon` 无法启动 | 确认程序目录可写、没有另一个实例运行，并执行 `status` 检查状态。 |
| TUI 无法打开 | 在桌面终端中运行 `manage`，或按 [安装与运行](installation.md) 配置 `SSH_MCP_TERMINAL`。 |
| SSH 连接失败 | 检查 IP、端口、账号密码和主机指纹；远端必须提供 Linux 命令环境。 |
| 数据库连接失败 | 检查 `IP:端口`、引擎、账号密码、TLS 策略和 CA 文件。 |
| 返回 `outcome_unknown` | 先人工核验远端实际状态，再提交明确的检查或重试请求；服务不会自动重放。 |
| 写 SQL 返回 `write_credential_not_configured` | 在 TUI 为该数据库填写可写账号；相同账号可复用只读密码。 |
