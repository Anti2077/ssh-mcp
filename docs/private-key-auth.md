# 私钥登录与菜单操作

这个分支增加 SSH 私钥认证和键盘菜单。主页用 `↑↓` / `Tab` 选择菜单，`Enter` 打开；目标列表和纵向操作菜单之间用 `Tab` 切换焦点，组内用 `↑↓` 移动，`Enter` 执行。表单用 `Tab` / `Shift+Tab` 切换字段和按钮，选中“验证并保存”后按 `Enter`。`Esc` 返回。旧字母快捷键保留兼容，但无需使用。

新增 SSH 时，在“认证方式”用 `←→` 选择“私钥登录”，填写本机私钥绝对路径或 `~/.ssh/id_ed25519`。支持 Go SSH 库可解析的 OpenSSH / PEM 私钥，包括带口令的私钥。私钥文件由本机 daemon 读取，路径作为本地元数据保存；文件和口令不写入数据库、备份、审计日志或 MCP 响应。私钥文件需要另外备份。

遇到加密私钥时，daemon 打开本地终端控制台（已有控制台则复用），由用户输入口令。口令只用于本地解析，解锁后的签名器仅缓存在当前 daemon 内存中，锁定、密钥维护或退出时丢弃；私钥文件变化后需重新解锁。MCP 调用返回 `unlock_required` / `ssh_key_unlock_required` 且 `execution_outcome=not_dispatched`，解锁后需重新发起操作，不会自动重放。若终端未自动出现，手动运行同一路径下的 `ssh-mcp manage`。首次连接和指纹变化仍须人工核对，确认按钮默认选中“返回”。

当前仍只接受 IP 地址和 Linux 远端语义；尚未接入 ssh-agent、硬件密钥或 `~/.ssh/config` 别名。
